## 👨🏻‍💻 &nbsp;About Me

<p>👋 &nbsp;Hi! I'm <strong>Ruan Anjos</strong>, a Full Stack Developer with a strong focus on Backend Engineering, currently working as a Software Engineer Intern at <strong>RGM Tecnologia</strong>.</p>

<p>💡 &nbsp;I'm passionate about <strong>Clean Architecture</strong>, <strong>SOLID principles</strong>, and <strong>Test-Driven Development (TDD)</strong> using Vitest. My work spans from structuring robust APIs to developing data-driven solutions and web applications.</p>

<p>🚀 &nbsp;Currently building scalable systems using <strong>TypeScript</strong>, <strong>Node.js</strong>, and <strong>Python</strong>, while managing workflows with strict Git hooks and Conventional Commits.</p>

<p>💼 &nbsp;I have built the <strong>Field Guide (GUIAFCA)</strong> PWA for offline botanical cataloging, developed the <strong>NeoLife</strong> full-stack hospital management system, and architected solutions for <strong>CERAC</strong> and the <strong>PET-Saúde</strong> program.</p>

<p>🎓 &nbsp;Undergraduate student in Computer Systems at <strong>Universidade Estadual do Piauí (UESPI)</strong> (Expected 2026)</p>
